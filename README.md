# Beconomia

Beconomia é um plugin de **economia para servidores Paper 1.21.1** feito em Java.  
Ele permite que jogadores vejam seus coins, transfiram entre si e que administradores definam valores de forma fácil.

## Comandos

- `/money` – Mostra a quantidade de coins do jogador que executar o comando.  
- `/topmoney` – Mostra o **Top 5** jogadores com mais coins.  
- `/money set <nick> <quantia>` – Define a quantia de coins de um jogador.  
  - Somente jogadores com a permissão `economia.setmoney` ou **OP** podem usar.  
- `/pay <nick> <quantia>` – Permite transferir coins para outro jogador.

## Permissões

- `economia.setmoney` → Permite usar `/money set`.
